# Multimedia Compression Toolkit
 (RLE + LZW Real Implementation)
  
  
  Overview
  
  The Multimedia Compression Toolkit is a Python desktop application that demonstrates real data compression techniques using classic algorithms such as Run-Length Encoding (RLE) and LZW (dictionary-based compression).

The project provides a graphical user interface (GUI) that allows users to:

Compress text or file data
Save compressed output as binary files
Decompress files back to original form
Visualize compression performance
This project bridges the gap between theory and real implementation of data compression algorithms.
