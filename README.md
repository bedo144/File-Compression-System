# Multimedia Compression Toolkit
 (RLE + LZW Real Implementation)
  
  
  ## Overview
  
  The Multimedia Compression Toolkit is a Python desktop application that demonstrates real data compression techniques using classic algorithms such as Run-Length Encoding (RLE) and LZW (dictionary-based compression).

The project provides a graphical user interface (GUI) that allows users to:

Compress text or file data
Save compressed output as binary files
Decompress files back to original form
Visualize compression performance
This project bridges the gap between theory and real implementation of data compression algorithms.


## Features

 File upload support
 Manual text input mode
 Real compression algorithms:
 Run-Length Encoding (RLE)
 LZW Compression (simplified working version)
 Decompression functionality
 Save compressed data as .bin file
 Compression size visualization
 User-friendly GUI built with Tkinter


 ## How It Works

### Compression Flow:
Load file or enter text
Choose compression algorithm
Apply encoding (RLE / LZW)
Generate compressed binary output
Save compressed file to disk


### Decompression Flow

Load .bin compressed file
Decode using selected algorithm
Restore original data


## Technologies Used

Python 3.x
Tkinter (GUI development)
File handling (binary + text processing)
Custom compression algorithms (RLE, LZW)
